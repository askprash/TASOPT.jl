## Notes

* Cost per evaluation: Julia median 34.2 ms (warm-started, initwgt=true after the first call) against 18.1 ms for Fortran, a ratio of 1.9. The 9.5 ms warm figure measured near the converged baseline was not reproduced along the optimization path (the cause was not investigated; trial points probably need more weight iterations). Julia's wall-time advantage therefore comes from needing fewer evaluations, not from faster sizing.
* All penalty-method optimizers settle where the quadratic penalties are partly violated (see the violation columns). The penalty weights, not the optimizer, set this; Fortran simpop ends the same way (span +0.23%, BFL +1.4%).
* Runs that hit a failed sizing (non-finite objective or exception) are counted in `nfail` in `runs_summary.csv`; the harness rebuilds the aircraft after such a failure so later evaluations are not contaminated.
* The Julia starting point differs from Fortran's: `example/737_compare_input.toml` has Tt4 1533/1487 K, while the Fortran run starts at 1833/1587 K; the committed copy uses the Fortran values.

The Julia and Fortran sizing models do not give identical numbers at the same design point (the starting objective is 263200 N in Julia against 244870 N in Fortran), so absolute objective values should not be compared across codes. Wall time, evaluation counts and constraint behavior are comparable.
